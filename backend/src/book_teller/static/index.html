Book Teller

A book, told well by one voice, and every script checked against the book.

Paste one chapter of a book that is free of copyright. The app writes a script that tells it, and then checks the script against the chapter. Only the owner can start a run and read it. The first answer can take a few seconds: the app sleeps when nobody visits.

This browser keeps the key for two days.

At most 5,000 words and 40,000 characters.
